# Sprint Recharge Rate

## Description
This mod increases the sprint recharge speed in REPO, making stamina recover faster. 

## Features
- 10x faster sprint recharge time (0.1s instead of 1s)
- 10x More stamina per recharge tick

## Installation
1. Make sure BepInEx is installed in your REPO folder
2. Download the mod from Thunderstore or git hub
3. Extract the files to your 'REPO/BepInEx/Plugins' folder (Thunderstore should do this for you)
4. Launch the game

## Configuration
Currently no configuration options. Values are hardcoded to:
- Recharge time: 0.1 seconds
- Recharge amount: 10x
